MDVClans 1.10.0 - Tiers de clan

ANTES DE ACTUALIZAR
- Haz backup de plugins/MDVClans/Data/clans.db
- Compila con Maven/GitHub y reemplaza el jar por MDVClans-1.10.0.jar
- No borres la carpeta del plugin si quieres conservar menús/config personalizados.

QUÉ AÑADE
- Tier de clan: Banda, Hermandad, Compañía, Gremio, Reino.
- /clan mejorar, /clan tier y /clan upgrade.
- El upgrade se paga con dinero del banco del clan.
- Permiso nuevo: tier-upgrade.
- Límites por tier: miembros, bases, almacén y aliados.
- Bases múltiples: /clan setbase [numero] y /clan base [numero].
- Almacén dinámico por tier; el tier Reino usa 3 páginas de 53 slots útiles.
- Placeholders internos para mostrar tier y límites en menús/lore.

MIGRACIÓN AUTOMÁTICA
- Se agrega clans.tier con default 0.
- Se crea clan_bases para soportar más de una base.
- Si un clan tenía base vieja, se copia automáticamente como base #1.
- La migración de bases corre una sola vez y marca mdvclans_meta.bases-migrated-1.10 = true.
- Los clanes existentes empiezan como Tier 0 Banda. No se expulsan miembros si ya superan el límite; solo se bloquean nuevas entradas/invitaciones hasta mejorar.
- El almacén viejo no se borra: si un clan baja visualmente a menos slots por tier, los items extra quedan guardados y reaparecen al desbloquear más espacio.
